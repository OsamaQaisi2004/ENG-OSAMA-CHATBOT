
# ENG OSAMA CHATBOT

An AI-powered chatbot built using Python, Streamlit, and NVIDIA API.

## Overview

ENG OSAMA CHATBOT is an interactive AI chatbot that allows users to submit questions and receive AI-generated responses.

## Technologies

- Python
- Streamlit
- OpenAI Python SDK
- NVIDIA API
- Moonshot AI (Kimi)

## Features

- Interactive chatbot interface.
- AI-powered question answering.
- Streaming responses.
- Integration with NVIDIA-hosted language models.

## Installation

Clone the repository:

```bash
git clone https://github.com/OsamaQaisi2004/ENG-OSAMA-CHATBOT.git
```

Enter the project directory:

```bash
cd ENG-OSAMA-CHATBOT
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Configuration

Create a `.env` file in the project directory.

Add your own NVIDIA API key:

```env
NVIDIA_API_KEY=your_api_key_here
```

Never upload your actual API key to GitHub.

## Run the Application

```bash
streamlit run SEC_CHAT.py
```

## Requirements

- Python 3.10+
- NVIDIA API account and API key
- Internet connection
